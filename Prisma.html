PRISMA / GUIA RÀPIDA

Dona forma al so.

Fitxers: obre o arrossega música. Tot es processa en aquest navegador; no s’envia a cap servidor. Diversos fitxers es reprodueixen en ordre.

Micròfon: accepta el permís del navegador. No el reproduïm pels altaveus, per evitar acoblaments. Prem el mateix botó per desconnectar-lo.

So del sistema: escolta tot el que surt pels altaveus (Spotify, YouTube, un reproductor…). Prisma busca una entrada que porti aquesta sortida: «Prisma · so del sistema», un «Monitor of…» (Firefox els mostra) o «Stereo Mix» a Windows. Chrome a Linux amaga els monitors: executa una vegada ./So-del-sistema.sh a la carpeta de Prisma i queda creada l’entrada virtual, també després de reiniciar (./So-del-sistema.sh desactiva la treu). No reproduïm aquesta entrada pels altaveus, i no cal cancel·lació d’eco.

Entrada d’àudio: el selector mostra les entrades que ofereix el navegador després de donar permís. Pots triar-hi a mà qualsevol entrada.

Filtres visuals: Greus, Mitjos i Aguts ajusten la influència de cada banda sense canviar el so. «Destaca els atacs» redueix el pes del so sostingut per recuperar el moviment dels cops.

Pestanya: només per a una pestanya concreta. Firefox no admet l’àudio de pestanyes amb aquesta API; fes servir «So del sistema». Amb Chrome/Edge, tria «Pestanya de Chrome/Edge», selecciona la pestanya que reprodueix música i activa «Comparteix l’àudio». Compartir la finestra sencera del navegador pot aportar només vídeo, sobretot a Linux. Si no arriba cap pista de so, Prisma ho explicarà i alliberarà la captura.

Demo sonora: una peça sintètica generada localment per provar la resposta real als greus i al ritme.

Dreceres: espai, reproducció/pausa; ←/→, univers; F, pantalla completa; H, amaga controls; Esc, recupera controls.

Prisma està inspirat en els visualitzadors clàssics. Els presets són originals i no carrega fitxers .milk o .milk2. La captura PNG desa només el visual.

Aquest HTML s’obre directament amb doble clic, sense servidor. El micròfon i la captura depenen dels permisos i del suport del navegador per a fitxers locals. No es pot forçar una captura que el navegador no ofereix. Els visuals poden contenir moviment i canvis de llum; pots pausar-los amb «Pausa visual», aquí mateix.
